# Data Analysis & Pattern Recognition: S4 Flipped Classroom

Clustering exercises for the UPC Master's course (Prof. Christian Mata).

- **Exercise 1:** k-means on the Palmer penguins dataset, evaluated with a confusion matrix and the adjusted Rand score
- **Exercise 2:** agglomerative clustering vs k-means on a small synthetic dataset, with a hand-written Euclidean distance function
- **Exercise 3:** choosing the number of components for a Gaussian Mixture Model on a sample of the diamonds dataset using BIC

Tools: Python, pandas, scikit-learn, seaborn, scipy.
